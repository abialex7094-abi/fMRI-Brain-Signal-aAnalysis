# Exploratory Data Analysis of fMRI Region-of-Interest (ROI) Signals During Rest and Cognitive Tasks

Project Overview

This project analyzes simulated functional Magnetic Resonance Imaging (fMRI) BOLD signals across five brain regions under different experimental conditions: Rest, Visual Task, and Memory Task.

The objective is to explore brain signal variations, compare regional activity, and understand correlations between brain regions using Python.

Tools & Technologies

* Python
* Google Colab
* NumPy
* Pandas
* Matplotlib
* Seaborn

Dataset Description

The dataset contains 120 simulated time points and five brain regions:

* Visual Cortex
* Prefrontal Cortex
* Hippocampus
* Motor Cortex
* Amygdala

Experimental conditions:

* Rest
* Visual Task
* Memory Task

Data Analysis Performed

* Generated simulated fMRI signal data using NumPy.
* Created a structured dataset using Pandas.
* Calculated average signal values across experimental conditions.
* Calculated Z-scores to standardize brain region signals.
* Analyzed correlations between brain regions.

Visualizations

1. Line Plot – fMRI BOLD signal changes over time.
2. Boxplot – Brain region activity across experimental conditions.
3. Correlation Heatmap – Relationships between brain regions.

Key Learning Outcomes

* Data generation and manipulation using NumPy and Pandas.
* Exploratory Data Analysis (EDA).
* Statistical analysis using mean, standard deviation, and Z-scores.
* Data visualization using Matplotlib and Seaborn.
* Understanding correlation analysis.

Note

This project uses synthetically generated fMRI-like data for educational and analytical purposes. It does not use actual patient scans or clinical data.
